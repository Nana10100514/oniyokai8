おにと、おさんぽ。最新版

フォルダ一式をHTTPSの公開先に配置してください。スマホのSafari・Chromeでカメラを許可して利用します。
浮遊する妖怪は画面上部、歩く妖怪は下部に同時に登場します。同じ列の提灯は前の妖怪から2秒あけて続きます。
海坊主は下から勢いよく飛び出し、少し留まってから下へ戻ります。狐は右端、狸は左端から繰り返し顔を出します。
からかさの足はPNGの元の太さを保っています。
端末実機での撮影・録画・保存は未確認です。

浮遊妖怪が交互に流れ続け、妖怪が全くいない時間はありません。鬼以外の妖怪にも薄い楕円のぼかし影を追加しました。狸は左、狐は右から顔を出します。

内カメラは映像全体が収まる表示です。端末の映像比率によって余白が出ます。ズーム制御に対応する端末では最小倍率に設定します。外カメラは従来どおり全画面表示です。

海坊主は縦横どちらの画面でも全体を覆う大きさで下から飛び出します。
